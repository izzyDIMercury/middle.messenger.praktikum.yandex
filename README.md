### Команды:

npm run dev `- запуск dev-сервера,`
npm run build `- сборка прокета,`
npm run start `- запуск локального Express-сервера с раздачей статики.`
npm run lint `- запуск линтеров eslint и stylelint`
npm run test `- запуск тестов`
npm run precommit `- запуск линтеров и тестов`

### Технологии, используемые в проекте:

Сборщик: Vite,
Язык: Typescript,
Шаблонизатор: Handlebars,
Препроцессор CSS: SASS,
Линтеры: ESLint, Stylelint,
Тестирование: Mocha, Chai, JSDom, Sinon, Sinon-Chai, TSNode

### Навигация по проекту:

- первой открывается страница входа, если пользователь залогинен, происходит редирект на страницу чата, для доступа к страницам логина и регистрации нужный выйти из профиля на странице настроек;

- в левом-верхнем углу ссылки на страницы с ошибками 404 и 500, после перехода на которые по кнопке `Назад` выполняется возврат на страницу входа;

- на странице входа по кнопке `Вход` выполняется переход на страницу с чатом, по кнопке `Нет аккаунта?` выполняется переход на страницу регистрации;

- на странице чата по кнопке в левом-верхнем углу (слева от строки поиска) выполняется переход на страницу профиля;

- на странице профиля (как и на страницах изменения пароля и данных) по кнопке `Вернуться` выполняется переход на страницу чата, по кнопкам `Изменить данные` и `Изменить пароль` выполняется переход на соответствующие страницы, откуда по кнопке `Сохранить` выполняется переход на страницу чата;

- для смены аватарки нужно на странице изменения данных нажать "Загрузить изображение", а потом "Изменить изображение";

- настройки и удаление чата доступны по клику по кнопке в правом верхнем углу на странице чата;
